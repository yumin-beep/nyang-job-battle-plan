# 취업하냥! — 백수 고양이 직업 쟁탈전

> “오늘도 백수로 살 순 없다냥. 저 일자리는 내 거다!”

게임가상현실 중간·기말 프로젝트를 위한 게임 기획서입니다. 기존 **3D 직업대전** 프로토타입을 바탕으로, 직업을 고르고 시작하던 방식을 **백수 고양이가 전투 중 일자리를 쟁탈하는 방식**으로 발전시키는 기획입니다.

이 저장소에는 과제용 `README.md`만 관리합니다. 아래 내용은 개발 목표이며, 기존 구현과 새로 개발할 기능은 10절에서 구분합니다.

## 2. 게임 컨셉

하루 종일 뒹굴던 백수 고양이들에게 채용 공고가 도착한다. 하지만 동네 취업센터가 뽑는 고양이는 단 한 마리다. 네 마리의 고양이는 면접 대신 몸싸움으로 자신의 자리를 차지하려 한다.

모든 플레이어는 같은 기본 능력을 가진 **백수 고양이**로 시작한다. 중앙 채용 구역을 차지하면 희망 직업에 취업하고, 제빵모자와 바게트 또는 경찰모와 장비처럼 직업에 맞는 외형과 능력을 얻는다. 다른 고양이가 자리를 빼앗으면 기존 취업자는 장비와 강화 효과를 잃고 다시 백수가 된다.

이 게임의 재미는 **취업 전후의 확실한 능력 차이**와 **언제든 자리를 빼앗길 수 있다는 긴장감**이다. 취업자는 강한 능력으로 자리를 방어하고, 백수들은 빈틈을 노려 점령을 방해하거나 취업자를 쓰러뜨린다. 모두 개인전이므로 잠시 같은 상대를 공격하더라도 최종적으로는 서로 경쟁한다.

### 핵심 키워드

- **Compete — 쟁탈:** 하나뿐인 채용 구역을 두고 경쟁한다.
- **Get a Job — 취업:** 구역에 혼자 3초 동안 머물러 직업을 얻는다.
- **Power Up — 강화:** 직업 전용 공격과 스킬로 전투 능력이 강해진다.
- **Defend & Retake — 방어와 탈환:** 일자리를 지키거나 다시 빼앗으며 취업 시간을 쌓는다.

## 3. 게임 목표

1. 백수 상태로 시작해 중앙 채용 구역으로 이동한다.
2. 다른 고양이를 밀어내거나 처치하여 혼자 점령할 기회를 만든다.
3. 채용 구역에 혼자 3초 동안 머물러 취업한다.
4. 직업 능력으로 생존하고 다른 고양이의 취업을 저지한다.
5. 실직하거나 쓰러지면 다시 도전한다.
6. 5분 종료 시 **누적 취업 시간이 가장 길면 승리**한다.

처치 수는 승리 점수가 아니다. 싸움은 취업 기회를 만들고 일자리를 지키기 위한 수단이다. 최고 누적 시간이 같으면 공동 우승으로 처리하고, 아무도 취업하지 못했다면 무승부로 처리하는 것을 기본안으로 한다.

## 4. Core Gameplay Loop

```text
백수 고양이로 시작
        ↓
채용 구역으로 이동 → 경쟁자와 전투
        ↓
구역에서 혼자 연속 3초 버티기
        ↓
취업 성공: 직업 장비·스킬·강화 효과 획득
        ↓
생존하며 자리 방어 → 누적 취업 시간 증가
        ↓
다른 고양이에게 탈환당함 / 사망
        ↓
실직: 백수 상태로 복귀
        ↓
다시 채용 구역에 도전

5분 종료 → 누적 취업 시간 비교 → 결과 발표
```

플레이어는 경기 내내 **쟁탈 → 취업 → 강화 → 방어 → 실직 → 재도전**을 반복한다. 사망한 경우에는 4초 뒤 부활하여 다시 도전한다.

## 5. 플레이어 조작

| 입력 | 기능 |
|---|---|
| W / A / S / D | 캐릭터 이동 |
| 마우스 이동 | 캐릭터의 조준·공격 방향 지정 |
| 마우스 왼쪽 버튼 | 기본 공격 |
| Space | 점프 |
| Q | 현재 상태의 스킬 1 |
| E | 현재 상태의 스킬 2 |
| 채용 구역 안에 머무르기 | 별도 버튼 없이 점령 시도 |

카메라는 쿼터뷰를 유지한다. Q와 E는 백수일 때 기본 생존·방해 스킬, 취업했을 때 직업 전용 스킬로 바뀐다.

## 6. 플레이어 기능

### 6.1 이동과 조준

- 맵 안에서 전후좌우로 이동하고 점프한다.
- 마우스 방향으로 몸을 돌려 공격한다.
- 장애물을 이용해 원거리 공격을 피하거나 접근 경로를 바꾼다.

### 6.2 백수 상태

- 모두 같은 기본 능력과 고양이 외형으로 시작한다.
- 기본 공격은 **냥냥펀치**이며, Q는 짧은 회피 이동, E는 가까운 상대를 밀어내는 동작을 기본안으로 한다.
- 직업 전용 공격보다 화력은 낮지만, 회피와 밀치기로 취업자에게 접근하고 점령을 방해할 수 있다.
- 외형 색상과 머리 위 표식으로 플레이어를 구분한다.

### 6.3 취업과 강화

- 로비에서는 취업 시 사용할 **희망 직업**만 선택한다. 경기 시작부터 능력을 얻는 것은 아니다.
- 점령을 완료하면 희망 직업의 장비를 착용하고 기본 공격·Q·E가 직업 능력으로 바뀐다.
- 직업에 맞는 공격력 또는 방어력 강화가 적용되어 백수 상태보다 전투에서 유리해진다.
- 강화 수치와 재사용 대기시간은 플레이 테스트로 조정한다. 직업을 반복 획득해도 강화가 중첩되지 않는다.

### 6.4 피해와 부활

- 공격을 받으면 체력이 감소하고, 체력이 0이 되면 사망한다.
- 사망한 플레이어는 점령 판정에서 제외되며, 4초 뒤 자기 시작 지점에서 백수 상태로 부활한다.
- 취업자가 죽으면 일자리는 즉시 빈자리로 돌아가고 취업 시간 누적도 멈춘다.
- 처치만으로 직업이 이전되지는 않는다. 처치한 고양이도 혼자 3초 동안 점령해야 한다.
- 이미 쌓은 누적 취업 시간은 실직하거나 사망해도 유지된다.

## 7. 직업 및 쟁탈 규칙

### 7.1 직업 구성

네 직업 모두 **고양이가 해당 직업을 얻는 형태**다. 동물 종족을 직업별로 나누지 않고 같은 고양이 몸체에 의상·장비를 바꿔 직업을 표현한다.

| 직업 | 역할 | 기본 공격 | Q 스킬 | E 스킬 | 외형 특징 |
|---|---|---|---|---|---|
| 빵집사장 | 근접 전투·자가 회복 | 바게트 스윙 | 밀가루 폭탄: 범위 피해와 둔화 | 갓 구운 빵: 체력 회복 | 제빵모자, 앞치마, 바게트 |
| 경찰 | 원거리 견제·제압 | 권총 사격 | 테이저건: 잠시 기절 | 진압 방패: 받는 피해 감소 | 경찰모, 제복, 방패 |
| 트레이더 | 빠른 공격·위험 감수 | 동전 던지기 | 몰빵: 체력 소모 후 강한 공격 | 상한가: 일시적 공격력 증가 | 넥타이, 서류가방, 동전 |
| 소방관 | 버티기·진입·밀어내기 | 소방도끼 | 물대포: 전방 공격과 밀치기 | 긴급출동: 전방 돌진 공격 | 소방 헬멧, 방화복, 호스 |

직업별 특징은 기존 프로토타입을 활용하되, ‘백수 대 취업자’ 구조에 맞춰 수치는 다시 조정한다. 초기 제작은 **백수 ↔ 빵집사장** 전환으로 재미를 확인한 뒤 나머지 직업으로 확장한다.

### 7.2 채용 구역 규칙

| 상황 | 처리 |
|---|---|
| 구역 안에 살아 있는 고양이가 1마리 | 현재 취업자가 아니면 3초 점령 진행 |
| 고양이가 2마리 이상 함께 있음 | 점령 불가, 진행 시간 초기화 |
| 점령 도중 구역을 벗어나거나 사망함 | 진행 시간 초기화 |
| 혼자 연속 3초 점령 완료 | 새 취업자로 변경, 이전 취업자는 즉시 백수로 복귀 |
| 현재 취업자 혼자 구역에 있음 | 직업 유지, 강화 중첩이나 점령 재시작 없음 |
| 취업자가 구역을 벗어남 | 생존해 있고 탈환당하지 않았다면 직업과 시간 누적 유지 |
| 다른 고양이가 탈환 시도 중 | 3초가 완료되기 전까지 기존 취업자의 시간 누적 유지 |
| 취업자가 사망하거나 방을 떠남 | 빈자리로 전환, 점령 진행 초기화, 시간 누적 중지 |

최초 취업과 탈환은 **동일한 ‘혼자 3초’ 조건**을 사용한다. 경기 중 취업자는 최대 1마리이며, 일자리에 취업자가 없으면 아무에게도 점수가 쌓이지 않는다.

### 7.3 역전 기회

취업자가 강해지는 만큼 백수에게도 일자리를 되찾을 방법이 필요하다. 백수의 밀치기는 3초 점령을 끊는 데 사용하고, 엄폐물은 강한 원거리 공격을 피할 기회를 제공한다. 취업자는 회복·방어 스킬의 재사용 대기시간을 관리해야 한다. 선취업자가 계속 이기는지, 백수에게 탈환 기회가 충분한지를 중점적으로 테스트한다.

## 8. 맵과 화면 구성

맵은 **고양이 동네의 취업센터 앞 광장**을 배경으로 한다. 중앙에는 하나의 채용 구역, 외곽에는 네 개의 시작 지점을 배치한다. 중앙으로 접근하는 길에 상자·벤치 등의 엄폐물을 두어 이동과 견제가 모두 가능하게 한다.

| 화면 요소 | 표시할 정보 |
|---|---|
| 화면 상단 | 남은 경기 시간, 현재 취업자와 직업 |
| 채용 구역 위 | 점령 진행도, 경합 여부, 빈자리 상태 |
| 점수판 | 플레이어별 누적 취업 시간과 순위 |
| 플레이어 HUD | 체력, 현재 상태, 기본 공격·Q·E 및 재사용 대기시간 |
| 사망 화면 | 부활까지 남은 시간 |
| 결과 화면 | 최종 누적 취업 시간과 우승자 |

캐릭터는 둥근 몸통과 짧은 팔다리의 단순한 3D 고양이로 제작한다. 취업 전후의 차이가 쿼터뷰에서도 보이도록 모자·의상·무기의 실루엣을 크게 구분한다.

## 9. AI 연습 모드

- 혼자 개발·테스트할 수 있도록 사람과 AI를 합쳐 최대 4마리로 플레이한다.
- AI도 백수로 시작해 채용 구역 이동, 경쟁자 공격, 단독 점령, 취업 후 방어를 수행하도록 확장한다.
- AI에게도 체력, 재사용 대기시간, 3초 점령, 4초 부활 규칙을 동일하게 적용한다.
- 온라인 모드에서는 사람과 AI를 섞어서 플레이할 수 있도록 한다.

1인 연습은 AI와의 플레이를 뜻한다. 인터넷 연결 없이 실행하는 별도 오프라인 모드는 이번 기본 범위에 포함하지 않는다.

## 10. 개발 현황 및 제작 계획

### 기존 프로토타입에서 활용할 기반

- Unity·Photon PUN 2 기반 멀티플레이 접속과 캐릭터 이동.

기존 버전은 직업을 선택한 상태로 경기를 시작한다. **백수 시작, 취업 시 강화, 탈환 시 실직, 취업자 사망 시 빈자리 전환은 새로 구현할 규칙**이다. 기존 기능도 새 규칙과 결합한 뒤 재검증한다.

### 핵심 검증 항목

- 모든 참가자가 백수로 시작하고, 점령 전에는 직업 강화가 적용되지 않는가?
- 혼자 연속 3초일 때만 취업하며, 다른 고양이가 들어오면 진행이 초기화되는가?
- 탈환 순간 직업과 강화가 이전되고, 이전 취업자의 시간 누적이 멈추는가?
- 취업자 사망 시 빈자리가 되며, 누구나 다시 점령할 수 있는가?
- 5분 종료와 동시에 점수 누적이 멈추고, 모든 화면에 같은 결과가 표시되는가?
- 백수에게 역전 기회가 있고, 취업했을 때 강해졌다는 차이가 느껴지는가?
